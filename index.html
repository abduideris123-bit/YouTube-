⚙️ GitHub Pages Setup

1

GitHub Repository ፍጠር

github.com → New Repository → ስም ጻፍ (ለምሳሌ yt-scheduler) → Create

2

index.html Upload አድርግ

Repository ውስጥ "Add file → Upload files" ጫን → index.html ፋይሉን ጫን → Commit changes

3

GitHub Pages አንቃ

Settings → Pages → Branch: main → Save → ጥቂት ደቂቃ ጠብቅ

የ Site ዋናው URL ይሆናል፦

4

console.cloud.google.com → Auth Platform → Clients → Web client 1 → Edit (✏️)

Authorised JavaScript origins ውስጥ ጨምር፦

https://[username].github.io

Authorised redirect URIs ውስጥ ጨምር፦

[username] = የ GitHub username ህ

5
