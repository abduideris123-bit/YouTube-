🛠️ Setup Guide
GitHub Actions — browser ዝግ ቢሆን ይሰራል ✅
🐙 GitHub Sync ቅንብር ⚠️ አልተቀናበረም
—
1

GitHub Gist ፍጠር

gist.github.com → New Gist → filename: yt-schedule.json → content: [] → Create secret gist

URL: gist.github.com/USERNAME/GIST_ID → ID ቁረጥ → ከላይ ያስቀምጡ

2

GitHub PAT ፍጠር

github.com → Settings → Developer settings → Tokens (classic) → Generate new token

✅ gist scope ብቻ ምረጥ → Generate → ወዲያው ቁረጥ (አንድ ጊዜ ብቻ ይታያል)

3

ቪዲዮ Download URL

GitHub Actions ቪዲዮ ፋይሎቹን browser ከ IndexedDB ማንበብ አይችልም።

ቪዲዮ ፋይሎቹን Google Drive (share → anyone with link) ወይም Dropbox ላይ ስቀሉ → direct download link ቀምጡ → ቪዲዮ ሲጨምሩ "Download URL" field ያስቀምጡ

4

GitHub Repo + Secrets

github.com → New private repo → yt-scheduler → yt-scheduler.yml ፋይሉን .github/workflows/ ውስጥ ያስቀምጡ

Repo → Settings → Secrets → Actions:

GIST_ID · MY_GITHUB_PAT · YT_CLIENT_ID · YT_CLIENT_SECRET · YT_REFRESH_TOKEN

💡 YT_REFRESH_TOKEN: DevTools → Application → Local Storage → yt_refresh

5

ጀምር! ✅

ቪዲዮ ጨምር → ቀን/ሰዓት ያዙ → GitHub Actions every 5 min ይፈትሻል → ሰዓቱ ሲደርስ YouTube ላይ ይለቃል — browser ዝግ ቢሆን!
