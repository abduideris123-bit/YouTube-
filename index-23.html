⚙️ Vercel Setup Guide
1

Vercel Account ፍጠር

vercel.com → Sign up with GitHub → Free plan ምረጥ

2

Project አስቀምጥ ወደ GitHub

yt-scheduler folder ፍጠር → files አስቀምጥ → GitHub repo ፍጠር → push

3

Vercel ላይ Deploy

vercel.com/new → GitHub repo ምረጥ → Deploy

Vercel URL ያሳያል፦

https://yt-scheduler-xxxx.vercel.app
4

Environment Variables ጨምር

Vercel → Project → Settings → Environment Variables

YT_CLIENT_ID = YOUR_GOOGLE_CLIENT_ID.apps.googleusercontent.com
YT_CLIENT_SECRET = YOUR_GOOGLE_CLIENT_SECRET
CRON_SECRET = (ማንኛውም ሚስጥራዊ ቁጥር)
5

Vercel KV (Database) አስቀምጥ

Vercel → Storage → Create Database → KV → Connect to project

6

Google Cloud Redirect URI ዘምን

Vercel URL-ህን ወደ Google Cloud authorized redirect URIs ጨምር፦

https://yt-scheduler-xxxx.vercel.app
7

index.html ውስጥ Backend URL ዘምን

ፋይሉ ውስጥ ይህን ፈልግ፦

const BACKEND = "YOUR_VERCEL_URL";

ወደ ይህ ቀይር፦

const BACKEND = "https://yt-scheduler-xxxx.vercel.app";
